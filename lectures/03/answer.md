# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：講座特有の内容を把握して回答できる
- `--trace` で見えたツール呼び出し（ツール名と引数）：
        [tool call]   search_glossary({'query': 'LoRA'})
        [tool call]   search_glossary({'query': 'QLoRA'})
- 1つの質問での LLM 呼び出し回数（`requests`）：2
- 追加したツールと、docstring に書いた説明：make_quiz
    指定した回の講義内容に基づくクイズを作る。
    返すのは、問題文と正解のペア。例:
        {"question": "問題文", "answer": "正解"}

## 宿題

- 取り組んだレベル：発展
- やったこと：adk_agent フォルダを作り、adk run で呼び直した
- 結果：演習で行った3つの質問を実行、回答が明らかな用語に関する質問は同等の結果、問題出題は定義から用語を答えるという、ツールの想定とは逆の問題を提示してきた。
- 気づき・疑問：--trace などは作らなかったが、make_quizを削除すると用語ではなく手法のメリットを聞くタイプの問題を提示するようになるので、make_quiz は活用されていたのだと思う。そのうえで、問題文と解がなぜ逆になったのかが気になった。
